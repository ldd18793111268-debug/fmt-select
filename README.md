# FMT 志愿者（供体）筛选流程及常见问题

本指南供有意参加粪便捐赠的志愿者阅读，帮助您了解参与条件、筛查流程及相关注意事项。

## 谁能捐

- **年龄：** 目前招募范围为 14 至 30 岁；低于这个年龄的儿童如有意向，可先报名咨询，由工作人员评估。未成年人须经监护人同意。
- **生活习惯：** 目前招募要求不吸烟、不饮酒。
- **健康状况：** 需结合问卷、粪便样本检测及体检等综合评估，报名不代表一定入选。
- **费用补贴：** 筛查及体检均免费，每次有效捐赠补贴 200 元（以中心最新公示为准）。

## 流程几步

1. **填写问卷：** 如实填写初筛问卷，工作人员评估后反馈结果。
2. **初筛评估：** 根据问卷情况，可能需要补充健康、饮食、用药及排便等信息；结果分为通过、暂缓或暂未通过。
3. **粪便采样：** 按工作人员安排领取或接收采样工具，完成采样并寄回。
4. **体检：** 通过前期筛查后，由工作人员预约体检，所有体检项目均免费。
5. **后续管理：** 入选后需配合日常健康情况跟进，如有身体不适或使用抗生素等药物，请及时告知工作人员。

## 常见问题

### 1. 为什么报名后还要筛查？

样本可能用于患者的相关临床治疗，因此需要综合评估志愿者的健康状况、生活习惯及相关检测结果。

### 2. 没有做过乙肝筛查怎么办？

请联系工作人员，可根据情况安排相关筛查，不要求必须提供既往检测报告。

### 3. 如何采集粪便样本？

采样工具包括一次性采样管、手套、采样盒及冰袋等。排便后，用采样管盖子上的小勺取适量粪便放入管内，拧紧盖子并充分摇匀。

### 4. 采样后需要注意什么？

采样管上写好姓名和采样日期，与冰袋一起装好，并尽快寄回。采样时尽量避免混入尿液；如有便秘或腹泻，请等排便情况稳定后再采样。

### 5. 每周必须捐赠一到两次吗？

不是硬性要求，每周一到两次是建议频率。具体时间需提前预约，并结合您的排便规律及中心实际需求安排。

### 6. 可以邮寄采样工具吗？

可以。工作人员可寄送采样工具；符合条件且人数较集中的单位，也可联系工作人员咨询上门收样安排。

### 7. 每次需要捐多少粪便？

成人每次样本量标准为 150 克，一般情况下一次排便即可满足；儿童不适用这一标准。

### 8. 什么时候发放 200 元补贴？

每次捐赠后，工作人员会立即称重；达到相应重量标准后，当场发放补贴，无需等待。

### 9. 体检前需要准备什么？

体检当天早上需空腹，可以少量饮水；前一晚尽量不吃夜宵并保持正常作息。建议上午 8 点到达体检中心，告知前台是微生态中心安排的体检。

### 10. 为什么身体健康也可能暂时不能入选？

筛选会综合考虑排便情况、近期用药、生活习惯、健康状况及相关检测结果。暂缓或暂未通过不代表身体一定有问题，具体情况可向工作人员咨询。

### 11. 参加后需要注意什么？

尽量保持规律作息、正常饮食和适量运动，避免吸烟、饮酒。如出现发热、腹泻、腹痛、便秘等情况，或使用抗生素及其他可能影响肠道菌群的药物，请及时告知工作人员。

### 12. 不想继续参加可以吗？

可以，是否参加完全尊重个人意愿。如暂时不方便或不想继续，请直接告知工作人员。
