常见问题解答
抽烟问题：由于我们招募健康志愿者，并不是报名就可以的，我们要从中筛选出符合我们标准的健康人，所以抽烟是我们需要特别关注的点，这对于身体肠道内的微生物影响非常大，另外也想建议您早点戒烟，这不仅是为了将来可能需要接受治疗的患者着想，也是为了是对您的健康着想

由于我们招募健康志愿者，并不是报名就可以的，我们要从中筛选出符合我们标准的健康人，所以抽烟喝酒是我们需要特别关注的点，尤其是抽烟哈，这对于身体肠道内的微生物影响非常大，另外呢也想建议您早点戒烟，这不仅是为了将来可能需要接受治疗的患者着想，也是为了是对您的健康着想

如需解释抗生素：抗生素包括：头孢类（头孢呋辛、头孢噻肟等），青霉素类（阿莫西林、氨苄西林等）、喹诺酮类药物（氧氟沙星、环丙沙星等）、大环内酯类（阿奇霉素、罗红霉素等）、氨基糖苷类（庆大霉素、阿米卡星等））

建议您近期观察一下自己的排便规律，可以选择在平时排便的时间段过来,这样您排完便就可以走了，还需要克重达标（150g），捐赠补助我们会以现金或者微信转账等方便的形式发给您

（管理）在供体管理期间，需要尽量保持规律、健康的生活方式，比如规律作息、正常饮食和适量运动，同时避免吸烟、饮酒，并尽量减少饮料以及辛辣、刺激性食物的摄入。
如果期间出现发热、腹泻、腹痛、便秘等身体不适，或者使用了抗生素以及其他可能影响肠道菌群的药物，也需要及时跟我们工作人员沟通，以便我们进行评估。
另外，供体需要有一定的时间配合后续管理维护，我们会组织活动跟进供体的日常生活习惯，表现好也会有额外奖励，但并不会打扰到供体的日常工作和生活，我们会选择在大家休息有空闲的时间。
